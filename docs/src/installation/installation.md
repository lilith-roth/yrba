# Installation

There are three main ways to install YRBA.

1. [Native Installation](./installation/native-setup.md)
2. [Docker Container](./installation/docker-setup.md)
3. [Arch Linux AUR](./installation/arch-aur.md)
4. [nixOS Module](./installation/nixos-module-setup.md)

The native installation will be directly installed in your system via Cargo,
Nix, or your Linux packages.

Meanwhile, the docker container allows a simple solution without a lot of setup,
and is perfect for servers that are already utilizing Docker.

After this continue to [Configuration](../configuration/configuration.md) to set
up your YRBA instance.
