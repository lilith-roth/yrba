# Contribute

All kinds of contributions are welcome, be it bug reports, documentation updates, or improvements to the application or
its tests, or even financial contributions.

All development is done directly on [GitHub](https://github.com/lilith-roth/yrba).

To find ways to contribute check out the [Issues](https://github.com/lilith-roth/yrba/issues) page as it contains all
known bugs, planned features, and more.
