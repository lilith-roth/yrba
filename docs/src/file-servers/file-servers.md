# File Servers

YRBA enables easy automatic uploads of your backups to different systems, and automatically deletes backups using a
configured amount of backups to keep.

Currently, the only supported upload method is **SFTP**

Check out the [SFTP](./file-server/sftp.md) page for instructions to configure SFTP uploads.


## Planned upload solutions

Multiple different upload solutions are planned for the future like:

- NFS
- File copy (For example to back up to an external drive)
- SMB
